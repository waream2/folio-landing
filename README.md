# folio-landing

Marketing landing page for [/folio](https://github.com/waream2/folio).

A single static HTML file. No build step. No framework. Just `index.html`.

## Deploy

Connect this repo to Vercel — it auto-detects as a static site (no config needed) and deploys `index.html` at the root.

## Edit

Open `index.html`. The page is self-contained: inline SVGs (twin slash mark, social icons, favicon as data URI), inline CSS, no JavaScript. Edit and push.
